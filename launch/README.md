# Инструменты ручной передачи и разрешённой публикации

Уже включены в общий проект. Актуальная точка входа — ../START_CODEX.txt.

- tools/model_handoff.py: локальный неизменяемый snapshot, не вызов модели.
- tools/check_publish.py: read-only проверка единственного remote и отобранного source-контента, не push.
- tests/: проверяет эти инструменты во временных каталогах.
- templates/: примеры, не выданные автоматически разрешения.

Запуск тестов из корня: `python -m unittest discover -s launch/tests -v`.
